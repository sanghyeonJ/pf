웹 개발자 정상현의 포트폴리오

안녕하세요! 웹 개발자 정상현입니다. 저는 다양한 웹 개발 프로젝트와 업무 경험을 보유하고 있으며, 최신 기술을 활용하여 사용자 친화적이고 시각적으로 매력적인 웹사이트를 만들 수 있습니다.

요약
안녕하세요. 4년 차 웹 퍼블리셔 출신으로 개발자로 성장하고 있는 정상현입니다.
시맨틱 마크업으로 웹 표준과 접근성을 준수하여 웹 접근성 인증 획득 경험이 있으며, 반응형 웹과 javascript·jQuery를 활용한 동적 UI 구현에 능숙합니다.
개발 역량을 넓히기 위해 교육과정에서 Java, JSP, SQL 등 백엔드 기술을 익혔고, 정보처리기사 자격증을 취득하며 개발 프로세스 전반을 이해하게 되었습니다.
현재는 React와 Spring Boot를 활용한 개인 프로젝트를 진행하며 프론트엔드부터 백엔드까지 직접 구현하고 있습니다.
github·svn 기반 협업과 디자이너, 개발자 등 타 직군과의 원활한 커뮤니케이션 경험을 바탕으로, 화면과 로직을 함께 이해하는 개발자로서 조직에 기여하겠습니다.
